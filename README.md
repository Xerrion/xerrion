**Pragmatic software engineer building tools that turn slow, manual work into boringly fast workflows.**

I have worked on everything from satellite ground stations and autonomous drone measurement systems to internal tooling for Denmark's biggest TV station and streaming service. I like code that is clear under pressure, useful in production, and simple enough to come back to six months later.

### What I am doing now

Building internal tools at [TV 2 Danmark](https://tv2.dk/) where the best compliment is:

> "That used to take two hours. Now it takes five minutes."

This GitHub is where my hobby projects, experiments, and self-taught rabbit holes live. Some are polished. Some are notes to future me. Most are still moving.

### What I tend to build

- Developer tools and small automations that remove repeated work
- Web apps and dashboards with practical UX over decorative complexity
- Backend services, scripts, and integrations that favor boring reliability
- Game addons, IoT experiments, Raspberry Pi projects, and "I wonder if..." prototypes

### Before this

I worked in satellite communications, building ground control software, autonomous flight logic, and data analysis tools for drone-based antenna measurement systems. That meant Qt, Python, ROS, RF payloads, and code that needed to behave while hardware was in the air.

Clients and domains included ESA, NATO, TERMA, satellite dishes, radar systems, and field measurements where a good error message beats a clever abstraction.
